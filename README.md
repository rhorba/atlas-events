# Atlas Events — Morocco-Wide Event Aggregator

RabatEvents works. Morocco has 4 other major cities with scattered event ecosystems and no unified platform.

## Problem
Economic conferences, startup summits, policy forums, and networking events in Casablanca, Marrakech, Tangier, and Agadir are impossible to discover in one place.

## Solution
RabatEvents scaled to all of Morocco: multi-city scraping pipelines, city-filtered calendar views, community event submissions, iCal subscription feeds, bilingual FR/AR.

## Stack
Next.js 15, TypeScript, PostgreSQL 16, Drizzle ORM, Cheerio (scraping), react-big-calendar, ical-generator, Vitest + Playwright, Docker, Vercel, Tailwind v4

## Builds On
RabatEvents — same architecture, 5 additional cities

## Key Roles
Event Organizer | Attendee | Admin
